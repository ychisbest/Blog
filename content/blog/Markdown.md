# Markdown 使用手册
今天开始学习 markdown 的使用，markdown 是一种轻量级的标记语言，它的语法简洁明了，易于学习和使用。以下是 markdown 的基本语法：

## 标题
```markdown
# 一级标题
## 二级标题
### 三级标题
#### 四级标题
##### 五级标题
###### 六级标题
```

## 文本样式
```markdown
**加粗**
*斜体*
~~删除线~~
```

## 列表
### 无序列表
```markdown
- 项目1
- 项目2
  - 子项目2.1
  - 子项目2.2
```

### 有序列表
```markdown
1. 项目1
2. 项目2
   1. 子项目2.1
   2. 子项目2.2
```

## 链接与图片
```markdown
[链接文本](URL)
![图片描述](图片URL)
```

## 引用
```markdown
> 引用内容
```

## 代码
### 行内代码
```markdown
`代码`
```

### 代码块
```markdown
```语言
代码块
```
```

## 表格
```markdown
| 表头1 | 表头2 |
| --- | --- |
| 内容1 | 内容2 |
| 内容3 | 内容4 |
```

## 分割线
```markdown
---
```

## 脚注
```markdown
文本[^1]

[^1]: 脚注内容
```
